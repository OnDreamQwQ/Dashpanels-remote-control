# Dashpanels Remote Control

把 Dashpanels 的面板搬到一个界面上，用手持遥控器远程操作它。

面板是用**它自己的方块实体渲染器**画的，所以：

- 每个模块的外观、位置、朝向都和世界里一模一样；
- 别的附属加的模块自动支持，这个模组不需要认识它们；
- 拖动旋转、Ctrl+滚轮缩放，点哪个模块就是点世界里那个模块。

## 依赖

| 模组 | 版本 | 必需 |
| --- | --- | --- |
| Minecraft | 1.21.1 | 是 |
| NeoForge | 21.1+ | 是 |
| [Dashpanels](https://modrinth.com/mod/dashpanels) | 2.0+ | 是 |

| [Create](https://modrinth.com/mod/create) | 6.0.10+ | 否（只有 Aeroworks 支持需要） |
| [Aeroworks](https://modrinth.com/mod/aeroworks) | 1.5.0+ | 否 |

**不需要** Drive By Wire —— 这个模组只做遥控，不碰线缆。

## 怎么用

1. 放一个 **面板链接终端** 贴着面板（或贴着面板的线缆、任意同类方块）。它会认领**整张 Dashpanels 网络**上的面板，不是只有挨着的那一块。
2. 再放一个 **面板遥控中心**，它和终端通过提示里的 `网络 ab12cd34` 认亲：放下时若手里拿着同类方块，就继承该方块的网络；**潜行 + 右键** 网络方块 = 把它清出自己的网络。
3. 遥控中心与终端在同一网络时，中心就用终端认领的那些面板。
4. 手上拿 **面板遥控器**，**潜行 + 右键** 中心完成绑定（再潜行右键一次解除）。
5. 右键空气打开遥控界面。

### 遥控中心的界面

空手右键中心打开，三页：

| 页 | 内容 | 操作 |
| --- | --- | --- |
| **终端** | 网络里每个终端的位置、名字和它认领的面板数 | 右键 = 改名 |
| **遥控器** | 绑定过这台中心的遥控器与在线状态 | 只读 |
| **玩家** | 所有者 + 可操作 / 仅修改名单 | 所有者可以加人（输入名字后点 `+ 可操作` / `+ 仅修改`）、左键切换级别、右键移除 |

看哪一台终端由**遥控器自己**记着：每个遥控器各存各的，两个玩家拿着各自的遥控器可以同时看不同的终端。换终端在界面里用 `+` / `-`、或 `Shift + 滚轮`，也可以在界面外用 `Shift + 滚轮` 直接换。

放下中心的玩家自动成为所有者；只有所有者能改权限。列表里的玩家离线也保留。

### Aeroworks 控制台

装了 [Aeroworks](https://modrinth.com/mod/aeroworks) 时，**终端**会把挨着它（或挨着它认领的面板）的控制台一起收进来，遥控界面里会和面板画在同一个空间中。

右键控制台上的模块 = 进入 Aeroworks 自己的操控会话（HUD 轴指示、鼠标拖动的就是它原本那套），和站在世界里的控制台前一样：

- 会话由服务端发起，控制器被别的玩家占用时会照常提示 busy；
- 要求能操作这台中心、站在中心 64 格内、控制台真的接在这台中心的终端上；
- Aeroworks 的会话本身是用玩家视线去够方块的，所以离远了会点不到 —— 请站在控制台 8 格以内。

没装 Aeroworks 时整套控制台功能自动消失，其它功能不受影响。

界面里：

| 操作 | 效果 |
| --- | --- |
| 左键拖动 | 旋转整个面板组 |
| Ctrl + 滚轮 | 缩放 |
| 右键模块 | 操作它（按住不放 = 持续调，和世界里一样） |
| 滚轮 | 在模块上调数值 |
| Shift + 滚轮 | 换到下一个 / 上一个终端 |
| `+` / `-` | 同上；`0` 回到看整页 |
| ESC | 先退出正在操作的模块，再按一次关界面 |

开着界面时会接管鼠标：指针被钉住并隐藏，拖动的位移直接喂给模块（所以旋钮、滑块这些都是靠拖的“手感”）。

## 配置

`config/dashpanels_remote_control-common.toml`：

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `cameraTilt` | 45 | 相机相对面板工作面倾斜的度数 |
| `perspective` | false | 关掉是正交投影（每块面板一样大），打开是透视 |
| `showCrosshair` | true | 界面上画准星 |
| `rotateSensitivity` | 0.55 | 拖动旋转的灵敏度 |
| `infoBox` | true | 左上角显示当前模块名和读数 |

## 已知限制

- 面板必须在客户端已加载的区块里（大约 128~160 格）。区块没加载时界面会提示，不会画空壳。
- 拖拽型模块（旋钮、滑块、拉杆这类）只能靠按住 + 拖动来调；它们没有可编程的“设定值”入口。
- 面板遥控中心必须贴在面板上（或贴着它的线缆），一个接收器对应它认领的那块面板。

## 从源码构建

Dashpanels 不在公开 maven 仓库里，所以要先手动放一份 jar：

```
libs/
└── dashpanels-2.1+neoforge1.21.1.jar
```

然后：

```powershell
.\gradlew.bat build
```

产物：`build/libs/Dashpanels-Remote-Control-1.21.1-<版本>.jar`
